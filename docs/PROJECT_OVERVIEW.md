# Обзор проекта

## Зачем нужен AI Guard

Корпоративный AI-ассистент может не только отвечать на вопросы, но и читать документы, получать данные из внутренних систем и инициировать действия. Это делает AI полезнее, но одновременно расширяет поверхность атаки.

AI Guard добавляет контролируемый слой между человеком, LLM и корпоративными ресурсами.

## Основные классы угроз

| Угроза | Что может произойти |
|---|---|
| Prompt Injection | пользователь пытается переписать правила модели |
| Indirect Prompt Injection | вредоносная инструкция спрятана в документе/tool result |
| Jailbreak | попытка заставить модель обходить ограничения |
| System Prompt Exfiltration | запрос внутренних инструкций |
| DLP leak | раскрытие чувствительных пользовательских/корпоративных данных |
| Secret leak | раскрытие API keys, токенов, паролей, private keys |
| Unsafe Tool Call | агент пытается выполнить опасное действие |
| Excessive Privilege | действие выходит за полномочия пользователя |

Стабильная версия должна проверять вход, внешний контент, tool calls, tool results и финальный ответ, а также сохранять события безопасности и аудит.
