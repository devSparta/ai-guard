# Команда и зоны ответственности

## Студент 1

Go backend, config, HTTP API, Auth/RBAC, PostgreSQL, migrations, repositories, chat, documents permissions, events, audit, approvals и общая интеграция.

## Студент 2

Prompt Injection, Indirect Prompt Injection, Jailbreak, System Prompt Exfiltration, DLP, Secret Detector, Risk Engine и security tests.

React UI: Login, Chat, Dashboard, Security Events, Policies, Documents, Approvals, Simulator.

## Студент 4

LLM Provider, Agent Runtime, Tool Registry, Tool Guard integration, Docker, Compose и CI.
