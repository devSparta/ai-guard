# ADR-001 — Modular Monolith

**Статус:** принято.

Команда состоит из четырёх человек. Разнесение логических подсистем в микросервисы на старте добавит сетевое взаимодействие, deployment pipelines и сложность диагностики.

Решение: версия 1.x реализуется как modular monolith на Go. Границы подсистем фиксируются интерфейсами. Отдельным процессом может быть только optional ML service.
